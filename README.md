A simple and efficient Task Management Application built with HTML, CSS, and JavaScript. This project demonstrates DOM manipulation, event handling, and localStorage persistence to keep tasks even after refreshing the page.


👉 Live Demo: TODO App (argha0508.github.io in Bing) ( https://argha0508.github.io/TodoApp/)



✨ Features


Add tasks with a title and due date

Display tasks in a neat grid layout

Delete tasks with a single click

Persistent storage using localStorage (tasks remain after refresh)

Responsive design for desktop and mobile

Simple, clean UI



🚀 Technologies Used


HTML5 → Structure of the app

CSS3 → Styling, grid layout, responsive design

JavaScript (ES6) → Core logic, DOM manipulation, localStorage handling
